## 🚀 Features

- Add images by pasting any valid image URL  
- Clean 3‑column grid layout  
- Remove any image with a single click  
- Smooth, minimal UI  
- Fully responsive on smaller screens  

---

## 🛠️ Technologies Used

- **HTML5** 
- **CSS3**
- **JavaScript (ES6)**

---

## 🧠 How It Works

- User enters an image URL  
- JavaScript creates:
  - a container  
  - an `<img>` element  
  - a remove button  
- The container is added to the gallery grid  
- Clicking **Remove** deletes that specific image
